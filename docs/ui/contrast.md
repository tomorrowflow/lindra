# Quiet Clarity tokens: contrast results

Generated by `scripts/contrast_check.py` on 9 November 2026 (WCAG 2 relative luminance, minimum 4.5 to 1 for text). The token values live in `lindra/static/css/quiet-clarity.css`; the script and this file change together.

## How the brand kit became tokens (ADR 0009)

| Brand kit colour | Token | Use |
| --- | --- | --- |
| Paper `#F7F5F0` | `--color-base-200` | page background, top bar, action bar |
| White `#FFFFFF` | `--color-base-100` | writing surfaces, sidebar, login card, button labels on Teal |
| Ink `#243331` | `--color-base-content` | text, icons |
| Teal `#245B57` | `--color-primary`, `--color-accent` | primary action, focus ring, selection, the symbol's brackets |
| Sage `#A8B9A7` | `--color-secondary` | muted tint only; never text (see the rejected pair) |

Adjusted values, each a darker or lighter step of the same hue, recorded as ADR 0009 asks:

| Token | Value | Why |
| --- | --- | --- |
| Paper, darker step `--color-base-300` | `#EAE6DD` | hover and disabled surfaces need one step below Paper |
| Ink, secondary text `--text-secondary` | `#4F5F5D` | Ink lightened until it reads as secondary while staying over 4.5 to 1 |
| Sage tint `--sage-tint` | `#E3E9E2` | Sage lightened to a surface tint for a selected row |
| Teal on the Sage tint `--teal-on-tint` | `#1B4542` | Teal darkened one step for text on the tint |
| Error `--color-error` | `#B43F46` | the Quiet Clarity theme kit's red (`docs/design/lindra/design-theme-prompt-kit.md`), always paired with an icon or label |
| Error tint `--error-tint` | `#FBEEEC` | the alert surface behind error text |
| Warning `--color-warning` | `#865810` | the theme kit's amber for stale drafts and clarification text |
| Warning tint `--warning-tint` | `#FFF2D9` | the theme kit's caution surface |
| Success text | `#2F6B4F` | green near Teal, darkened until it passes as text |

The theme kit also proposes its own paper, ink and primary values. The tokens keep the brand kit's Paper, Ink and Teal because ADR 0009 names the brand kit as their source.
