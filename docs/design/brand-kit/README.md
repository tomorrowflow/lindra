# Lindra – Editorial Brackets brand kit (2026-11-08)

Colours: Teal #245B57 · Sage #A8B9A7 · Ink #243331 · Paper #F7F5F0 · White
Wordmark: "lindra", Source Sans 3 SemiBold, converted to outlines (no font needed).

symbol/  – symbol only (tight box): color, teal, ink, white, reversed; SVG + PNG 128/256/512/1024 (height). small-color.svg = simplified 2-line version for <24 px.
lockup/  – horizontal + stacked lockups (color, teal, ink, white, reversed); SVG + PNG 400/800/1600 width; wordmark-ink.svg.
web/     – favicon.svg (adapts to dark mode), favicon.ico (16/32/48), favicon-16/32/48.png, apple-touch-icon.png (180),
           icon-192/512.png, icon-maskable-192/512.png, og-image-1200x630.png, site.webmanifest, head-snippet.html.
app/     – ios-app-icon-1024.png (full bleed, no alpha – iOS rounds itself), ios/ icon-20…180 + 1024,
           android/ ic_launcher mdpi–xxxhdpi, adaptive foreground + monochrome 432 px (safe zone 66 %), play-store-512.png,
           SVG masters (square, rounded, maskable, foreground, monochrome).

Min. size: full symbol ≥ 24 px; below that, use the favicon tile (2 lines, thicker strokes).
Clear space: at least the height of a writing line around it.
